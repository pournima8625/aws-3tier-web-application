\# AWS 3-Tier Web Application



\## Objective



The objective of this project is to deploy a secure and highly available web application on AWS.



\## AWS Services



\- Amazon VPC

\- EC2

\- RDS

\- Application Load Balancer

\- IAM

\- Security Groups



\## Steps



1\. Created VPC.

2\. Created Public and Private Subnets.

3\. Created Internet Gateway.

4\. Created NAT Gateway.

5\. Created Route Tables.

6\. Launched EC2 Instances.

7\. Configured Security Groups.

8\. Created Load Balancer.

9\. Created RDS Database.

10\. Tested the application.



\## Result



The application was successfully deployed and accessed through the Load Balancer.
